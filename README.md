# EJ Partners assurances CRM 

J’aimerais créer un site internet pour mon cabinet de courtage en assurances en france

Notre positionnement est basé sur 2 expertise : 

L’assurances emprunteur 

L’accompagnement des parents sociaux dans la transmission de leur patrimoine 



Je souhaite un site moderne avec des cas concret et un simulateur de gains dédié à l’assurances emprunteur.

on dois avoir un blog



Notre site dois être au top pour le référencemeny Google internet mais également dédié au agent IA comment chat GPT afin d’être une sources d’information pour les IA
